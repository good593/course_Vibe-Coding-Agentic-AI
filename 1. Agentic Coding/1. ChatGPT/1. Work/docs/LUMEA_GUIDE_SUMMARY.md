# LUMEA 브랜드·캠페인 가이드 핵심 요약

> Google Drive의 `candle_drive` 폴더에 있는 브랜드 가이드와 캠페인 가이드를 바탕으로 정리한 문서입니다.

## 한눈에 보는 핵심

LUMEA는 캔들 자체보다 **향과 빛을 통해 하루의 속도를 낮추는 작은 쉼의 경험**을 제안하는 라이프스타일 브랜드다. 모든 브랜드 활동은 제품 기능이나 할인보다 캔들을 사용하는 순간, 달라지는 공간의 분위기, 선물로서의 경험을 우선해 전달해야 한다.

## 1. 브랜드 정체성

- **브랜드 정의:** 바쁜 하루의 끝에 작은 쉼의 의식을 만들어 주는 라이프스타일 캔들 브랜드
- **Mission:** 향과 빛을 통해 누구나 일상 속에서 짧고 온전한 휴식을 경험하게 한다.
- **Vision:** 집에서 보내는 시간을 더 감각적이고 의미 있게 만드는 대표 홈 프래그런스 브랜드가 된다.
- **Core Values:** Calm · Warmth · Craft · Simplicity
- **Brand Promise:** 불을 켜는 순간, 공간의 속도를 낮춥니다.
- **Tagline:** Light the pause. / 잠시, 빛을 켜세요.

## 2. 핵심 타깃

### 25~39세 직장인·1~2인 가구

- 퇴근 후 짧게라도 분위기를 전환하고 휴식하고 싶어 한다.
- 홈 인테리어와 감성적인 자기관리에 관심이 있다.

### 선물 구매자

- 친구, 동료, 연인에게 줄 선물을 찾는다.
- 취향 있어 보이면서도 부담스럽지 않고 고급스러운 선물을 원한다.

### 라이프스타일·홈스타일링 관심층

- 인테리어, 카페, 소품 콘텐츠를 즐겨 본다.
- 사용하지 않을 때도 공간을 완성하는 아름다운 오브제를 선호한다.

## 3. 브랜드 말투와 카피 원칙

말투는 **차분하고 따뜻하며 감각적이고 간결하게** 유지한다.

### 권장 표현

- 오늘의 속도를 조금 낮춰보세요.
- 무화과와 시더우드가 포근하게 남습니다.
- 불을 켜고, 하루를 내려놓습니다.
- 당신의 저녁에 작은 빛을 더합니다.

### 피해야 할 표현

- 지금 당장 힐링하세요!
- 향이 진짜 대박이에요.
- 최고급 프리미엄 감성 힐링 캔들입니다.
- 구매하지 않으면 후회합니다.

### 작성 원칙

- `힐링`, `감성`, `프리미엄` 같은 추상적 표현만 반복하지 않는다.
- 향 노트, 공간, 시간대, 사용 장면을 구체적으로 묘사한다.
- 강한 구매 압박, 과장된 최상급 표현, 가벼운 유행어를 피한다.
- 제품의 스펙보다 제품이 만들어 주는 순간과 감정을 먼저 보여준다.

## 4. 컬러와 타이포그래피

| 컬러 | HEX | 권장 용도 |
|---|---|---|
| Lumea Green | `#66735A` | 로고, 제목, 패키지 포인트 |
| Warm Cream | `#F5F0E6` | 주 배경, 상세페이지 |
| Sand Beige | `#D8C7AD` | 보조 배경, 라벨 |
| Cedar Brown | `#8A6F5A` | 향 노트, 강조 요소 |
| Charcoal | `#343530` | 본문, 정보성 텍스트 |

### 글꼴 원칙

- 한글 제목: 맑은 고딕 Bold 또는 Pretendard Bold 계열
- 한글 본문: 맑은 고딕 Regular 또는 Pretendard Regular 계열
- 영문 로고와 향 이름: 감성적이고 정제된 세리프 계열
- 한 화면에서 글꼴은 2종 이내, 굵기는 3단계 이내로 제한

## 5. 로고와 패키지 원칙

- 기본 로고는 `LUMEA` 워드마크를 사용한다.
- 로고 주변에 글자 높이의 최소 1/2 이상 여백을 확보한다.
- 사진 위에서는 충분한 명도 대비가 확보될 때만 흰색 또는 단색 로고를 사용한다.
- 로고를 늘이거나 기울이거나 그림자·외곽선을 추가하지 않는다.
- 패키지는 크림·베이지 바탕과 그린·브라운 포인트를 기본으로 한다.
- 전면 라벨 정보는 `브랜드명 → 향 이름 → 핵심 향 노트 → 용량` 순서로 배치한다.

## 6. 이미지 무드

### 권장 방향

- **시간대:** 해 질 무렵, 저녁, 이른 밤
- **조명:** 자연광이나 낮은 색온도의 따뜻한 간접광
- **공간:** 우드, 리넨, 세라믹, 책, 차가 있는 생활감 있는 미니멀 공간
- **장면:** 창가, 침실, 책상, 소파 옆 테이블 등 실제 사용 공간
- **소품:** 니트, 책, 머그, 나무 트레이, 식물, 과일 등 향과 계절을 연상시키는 요소
- **인물:** 얼굴 중심보다 손, 실루엣, 제품을 사용하는 순간 중심
- **제품 표현:** 불꽃과 라벨이 함께 보이게 하되 과도하게 연출하지 않는다.

### 피해야 할 방향

- 과도한 색 보정과 복잡한 소품
- 형광색이나 지나치게 상업적인 스톡 이미지
- 산타, 눈꽃 등 전형적인 크리스마스 장식의 과도한 사용

## 8. 겨울 캠페인 개요

- **캠페인명:** WINTER PAUSE — 겨울, 잠시 머무는 빛
- **핵심 제품:** Cedar Night / Quiet Fig / Winter Gift Set
- **핵심 메시지:** 추운 계절, 집 안에 가장 따뜻한 시간을 켜세요.
- **전략적 관점:** 향초 구매가 아니라 하루를 마무리하는 작은 의식과 선물 경험을 전달한다.

문서에 기재된 캠페인 기간은 11월 15일부터 12월 31일까지이나, **교육용 가상 일정**이므로 실제 실행 전에 확정해야 한다.

## 9. 캠페인 목표

- 겨울 컬렉션의 브랜드 인지도와 제품 관심도 확보
- 선물 세트 구매 전환 촉진
- SNS에서 저장·공유할 수 있는 감성 콘텐츠 축적
- 신규 고객의 첫 구매 유도
- 시즌 종료 이후 재구매 기반 마련

## 10. 메시지 흐름

| 단계 | 메시지 예시 |
|---|---|
| Attention | 겨울이 길어질수록, 집 안의 빛은 더 따뜻해야 하니까. |
| Interest | 시더우드와 앰버가 천천히 번지는 깊은 겨울 향. |
| Desire | 책 한 권, 따뜻한 차 한 잔, 그리고 LUMEA의 작은 불빛. |
| Action | WINTER PAUSE 컬렉션을 만나보세요. |

## 11. 채널별 콘텐츠 방향

| 채널 | 콘텐츠 | 목적 | CTA 예시 |
|---|---|---|---|
| Instagram Feed | 제품·공간 이미지, 캐러셀 | 브랜드 무드와 향 스토리 전달 | 겨울 향 보기 |
| Instagram Reels | 점화 전후 공간 변화 10~15초 영상 | 사용 경험 전달 | 당신의 저녁을 켜보세요 |
| Story | 향 취향 투표, 카운트다운 | 참여와 출시 기대감 형성 | 내 향 찾기 |
| 상세페이지 | 향 노트, 사용 장면, 선물 구성 | 구매 판단 지원 | 컬렉션 구매 |
| Email | 출시, 선물 추천, 마감 안내 | 재방문과 구매 전환 | Gift Set 확인 |

SNS 피드는 제품 사진 50%, 사용 장면 30%, 향·브랜드 스토리 20% 정도로 구성한다. 상세페이지는 `어떤 향인가`보다 `어떤 순간을 만드는가`를 먼저 보여준다.

## 12. 캠페인 운영 단계

| 단계 | 기간 | 주요 활동 |
|---|---|---|
| Teaser | D-14 ~ D-7 | 컬러·향 노트 티저, 카운트다운 |
| Reveal | D-6 ~ D-1 | 제품 공개, 향 스토리, Gift Set 공개 |
| Launch | D-Day ~ D+7 | 메인 영상, 상세페이지, 이메일, SNS 집중 노출 |
| Sustain | D+8 ~ D+30 | 사용자 후기, 상황별 추천, 선물 콘텐츠 |
| Last Call | 마지막 7일 | 시즌 종료와 배송 마감 안내 |

## 13. KPI 예시

| 목표 | 지표 | 교육용 목표 예시 |
|---|---|---|
| 인지 | 도달수, 영상 조회수 | 캠페인 전월 대비 30% 증가 |
| 관심 | 저장, 공유, 상세페이지 방문 | 콘텐츠 저장률 5% 이상 |
| 전환 | 구매 전환율, Gift Set 판매량 | 구매 전환율 3% 이상 |
| 관계 | 신규 구독, 재방문 | 신규 이메일 구독 300명 |

위 수치는 모두 교육용 예시이므로 실제 예산, 채널 규모, 과거 성과를 기준으로 다시 설정해야 한다.

## 14. 필수 제작물

- 메인 키비주얼 1종: 캠페인명, 제품, 겨울 무드 포함
- SNS 피드 6종: 제품, 사용 장면, 향 스토리
- 릴스 2종: 점화 장면과 공간 변화
- 상세페이지: 향 노트, 추천 상황, 선물 구성
- 이메일 3종: 출시, 선물 추천, 마감 안내
- 광고 소재: 1:1 및 4:5 비율, 짧은 헤드라인

## 15. 실무 운영 원칙

1. 모든 결과물에서 브랜드 컬러, 말투, 이미지 무드를 일관되게 유지한다.
2. 제품의 기능보다 사용 순간과 감정의 변화를 먼저 전달한다.
3. 추상적인 감성어 대신 향 노트와 생활 장면을 구체적으로 제시한다.
4. 할인보다 계절 경험과 선물 가치를 먼저 전달한다.
5. 겨울 분위기는 절제해서 표현하고 전형적인 크리스마스 장식을 남용하지 않는다.
6. 성과가 낮은 소재는 헤드라인, 첫 화면, CTA 중 한 요소만 변경해 테스트한다.
7. 제작 전 브랜드 톤, 컬러, 향 표현, 사용 경험, 로고·텍스트 가독성을 점검한다.
