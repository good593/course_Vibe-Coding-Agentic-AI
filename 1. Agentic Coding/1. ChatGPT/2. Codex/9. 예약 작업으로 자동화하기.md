# 8. 예약 작업으로 자동화하기

## 검증된 데이터 점검을 정해진 시간에 실행하기

시작: 7장의 healthy-day-data-audit 수동 검증 완료

결과: 예약 설정 → 실제 실행 확인 → 일시 중지

이 장의 예약 생성은 **ChatGPT 데스크톱 앱**에서 진행합니다.

---

## 먼저 경험할 문제

CSV가 바뀔 때마다 같은 품질 점검을 수동으로 실행합니다.

반복 가능하지만 실행 시점은 사람이 기억하고 있습니다.
스킬이 하는 일과 예약이 정하는 시간을 분리합니다.

이번 예약은 데이터 점검과 보고만 수행합니다.
마이그레이션·자동 수정·커밋·Groq 호출은 예약하지 않습니다.

---

## 단계 1. 실행 환경 확인

현재 공식 문서 기준:

- VS Code 확장에는 예약 작업 관리 화면이 없습니다.
- 데스크톱 앱은 로컬 프로젝트의 예약 작업을 다룰 수 있습니다.
- 로컬 파일이 필요한 예약은 PC와 앱이 실행 중이어야 합니다.
- 웹 예약은 PC의 로컬 폴더를 직접 사용할 수 없습니다.

계정·워크스페이스에서 해당 기능이 보이는지 확인합니다.
자료 확인일: 2026-09-21. 수업 전 실제 화면을 다시 확인합니다.

---

## 단계 2. 같은 프로젝트 열기

데스크톱 앱에 학생의 `project` 폴더를 연결합니다.

```text
현재 작업 폴더와 ../data의 CSV 3개,
.agents/skills/healthy-day-data-audit/SKILL.md를 확인해줘.
파일 내용을 임의로 바꾸지 마.
```

가상환경·데이터·스킬이 모두 보이는지 확인합니다.
VS Code에서의 성공만으로 다른 실행 환경의 성공을 가정하지 않습니다.

---

## 단계 3. 예약 프롬프트를 먼저 수동 실행

```text
healthy-day-data-audit 스킬을 적용해 CSV 품질을 점검해줘.
작업 위치는 현재 project 폴더야.
원본 CSV와 DB는 수정하지 말고 점검 보고서만 작성해줘.
파일별 행 수, 누락값, 구조 오류와 실행 실패 여부를 요약해줘.
데이터 출처의 최신성·정확성을 검증했다고 주장하지 마.
네트워크 연결이나 Groq 호출은 필요하지 않아.
```

보고서와 실제 실행 명령을 확인합니다.

---

## 단계 4. Scheduled에서 작업 생성

앱의 **Scheduled** 화면에서 새 작업을 만듭니다.
설치 버전에서 생성 버튼을 찾기 어렵다면 앱에 예약 생성을 요청합니다.

| 설정 | 이번 실습의 값 |
| --- | --- |
| 이름 | 건강한하루 CSV 품질 점검 |
| 프로젝트 | 학생의 project 폴더 |
| 프롬프트 | 앞에서 수동 검증한 프롬프트 |
| 실행 시점 | 현재 시각보다 약 5분 뒤의 확인 가능한 시각 |
| 시간대 | Asia/Seoul인지 확인 |
| 실행 위치 | 현재 로컬 프로젝트 |

저장 전에 표시된 **다음 실행 시각**을 확인합니다.

---

## 로컬 폴더와 worktree 선택

이번 첫 예약은 로컬 폴더를 사용합니다.
보고서 외에 파일을 수정하지 않도록 프롬프트를 제한합니다.

worktree로 바꾸려면 별도 점검이 필요합니다.

- 커밋하지 않은 코드·스킬·데이터는 없을 수 있습니다.
- `.env`, `.venv`, 로컬 DB는 자동으로 준비되지 않을 수 있습니다.
- 새 작업 경로에서도 `uv sync --locked`와 데이터 읽기가 가능한지 봅니다.

작업 공간이 다르면 수동 성공 결과를 그대로 적용할 수 없습니다.

---

## 단계 5. 첫 실제 실행 확인

다음 실행 시각이 지난 후 Scheduled의 실행 기록을 엽니다.

- 실제 실행 시각과 상태
- 사용한 프로젝트와 작업 위치
- 데이터 점검 스킬/스크립트의 실행 기록
- 생성된 보고서와 CSV별 행 수
- 승인 대기·실패·미실행 여부

등록 화면이나 수동 실행만으로 예약 성공을 판정하지 않습니다.

---

## 단계 6. 반복 일정으로 변경

첫 실행이 성공했다면 학습용으로 다음 일정을 설정해 봅니다.

> 매일 오전 9시, Asia/Seoul

다음 실행 시각이 의도와 일치하는지 확인합니다.
로컬 실행은 PC·앱·프로젝트 경로가 사용 가능해야 합니다.

수업이 끝날 때는 불필요하게 반복되지 않도록 일시 중지합니다.

---

## 실패할 때 확인할 순서

1. 작업이 활성 상태이고 시간대가 맞는지 확인합니다.
2. PC와 앱이 켜져 있었는지 확인합니다.
3. 선택한 프로젝트와 CSV 경로를 확인합니다.
4. 같은 앱에서 동일 프롬프트를 수동 실행합니다.
5. 무인 실행에서 필요한 권한 때문에 대기했는지 확인합니다.

문제 해결을 이유로 전체 컴퓨터 권한을 일괄 허용하지 않습니다.

---

## 예약 기능을 사용할 수 없는 경우

7장까지 수행하고 앱 예약 실습은 `미실행`으로 기록합니다.
강사가 예약 기능이 있는 환경에서 시연할 수 있습니다.

선택 대안은 Windows 작업 스케줄러에서
동일한 Python 점검 스크립트를 예약하는 것입니다.
이 경우 **OS 스크립트 예약**이며 Codex 예약을 실행한 것은 아닙니다.

웹 작업에 로컬 경로를 적어 놓고 실행 가능하다고 판단하지 않습니다.
