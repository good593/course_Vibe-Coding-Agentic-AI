# 6. MCP로 외부 정보 연결하기

## 최신 공식 문서를 작업의 근거로 사용하기

시작: 4장 설정 확인. 5장 코드와 무관하게 연결 연습 가능

결과: 문서 MCP 연결 + 실제 도구 호출과 출처 기록

---

## 먼저 경험할 문제

설정·스킬의 문서를 검색해서 매번 채팅에 붙여 넣고 있습니다.
기억만으로 작성한 경로나 설정 키가 현재 버전과 다를 수 있습니다.

이번 장에서는 공식 OpenAI Docs MCP를 연결해
다음 장에서 쓸 Codex Skill의 형식을 확인합니다.

이 연결은 개발 도구인 Codex용입니다.
서비스의 Groq RAG 검색 기능은 9장에서 별도로 구현합니다.

---

## 단계 1. 연결 전 답변 기록

```text
우리 프로젝트에서 반복 검증을 스킬로 만들려고 해.
저장 위치, 필수 메타데이터, VS Code Codex에서 호출하는 방법을
설명해줘. 현재 연결된 도구로 공식 문서를 확인할 수 없다면
기억에 의한 설명인지 명시해줘. 파일은 아직 만들지 마.
```

내용뿐 아니라 출처·확인 시점·도구 사용 여부를 기록합니다.

---

## 단계 2. Codex의 MCP 설정 열기

VS Code **Codex 확장**의 톱니바퀴 → MCP servers를 엽니다.
Add server에서 Streamable HTTP를 선택합니다.

| 항목 | 값 |
| --- | --- |
| 이름 | `openaiDeveloperDocs` |
| URL | `https://developers.openai.com/mcp` |

저장 후 Restart extension을 선택합니다.
VS Code의 다른 확장용 MCP 설정 화면과 구분합니다.

---

## 대안: TOML로 같은 서버 등록

UI에서 추가했다면 중복 등록하지 않습니다.
기존 `.codex/config.toml` 끝에 다음 블록만 합칠 수 있습니다.

```toml
[mcp_servers.openaiDeveloperDocs]
url = "https://developers.openai.com/mcp"
```

4장의 권한 설정을 지우지 않습니다.
신뢰된 프로젝트인지 확인하고 확장을 재시작합니다.

---

## 단계 3. 연결 상태 확인

MCP 서버 목록에서 활성화·오류 상태를 확인합니다.

```text
openaiDeveloperDocs MCP에서 사용할 수 있는 문서 조회 도구를
확인해줘. Codex 스킬의 작성과 로컬 탐색에 대한 공식 문서를
검색하고 해당 페이지를 실제로 읽어줘.
도구를 사용할 수 없다면 다른 방법을 쓴 척하지 말고 알려줘.
```

연결 등록과 실제 도구 호출 성공을 각각 확인합니다.

---

## 단계 4. 근거를 개발 결정에 반영

```text
읽은 공식 문서를 근거로 healthy-day-review 스킬의
저장 경로, name/description, 명시적 호출 방법을 정리해줘.
공식 URL과 적용할 결정을 docs/reports/06-mcp-skill-design.md에 저장해줘.
우리 프로젝트에서 스킬이 수행할 검증 명령은 README와
AGENTS.md를 읽고 결정해줘. 아직 스킬 파일은 만들지 마.
```

외부 문서의 사용법과 저장소의 실행 방법을 함께 사용합니다.

---

## 단계 5. 연결 전후 비교

| 비교 대상 | 기록할 내용 |
| --- | --- |
| 저장 위치 | 기억에 의한 경로와 확인한 경로 |
| 호출 방법 | 현재 IDE에서 사용할 방법 |
| 근거 | 실제 열어본 공식 URL |
| 불확실성 | 문서로 확인하지 못한 내용 |
| 도구 | 실행 기록에 나타난 MCP 호출 |

답변이 같더라도 근거를 확인한 과정이 학습 결과입니다.

---

## 단계 6. 실패 상황과 복구

- 목록에 없음: 다른 확장 설정인지, 프로젝트 설정이 로드됐는지 확인
- 연결 오류: URL·네트워크·기관 정책을 확인
- 등록 후 미반영: 확장을 재시작하고 새 채팅에서 재시도
- 도구 호출 없이 답변: 실제 검색·본문 조회를 명시적으로 요청

연결이 안 되면 공식 웹 문서로 나머지 수업을 진행할 수 있습니다.
단, 기록에는 **MCP 미완료·웹 조회로 대체**라고 적습니다.

---

## 확장 과제: DB 조회 MCP 설계

선택 과제이며 외부 DB MCP를 무조건 설치하지 않습니다.

```text
우리 실습 DB의 테이블 구조·건수·누락값을 Codex가 조회하는
읽기 전용 MCP 도구를 설계해줘. 임의 SQL 실행 대신 허용한
조회 도구만 제공하는 방식과 인증·접근 범위를 설명해줘.
서버 구현이나 연결 변경은 하지 말고 설계만 제안해줘.
```

문서 조회와 DB 쓰기는 필요한 권한과 영향이 다름을 설명합니다.
