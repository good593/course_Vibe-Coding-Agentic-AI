# ChatGPT Work 사용 준비와 설치

웹 또는 데스크톱 앱에서 Work를 시작하기

---

## 오늘의 목표

- ChatGPT Work의 사용 조건을 확인한다.
- 웹과 데스크톱 앱의 차이를 설명한다.
- 운영체제에 맞게 ChatGPT 앱을 설치한다.
- 로그인 후 Work를 선택하고 첫 작업을 실행한다.
- 로컬 파일 권한을 안전하게 설정한다.

---

# 1. ChatGPT Work 사용 조건

---

## 먼저 알아둘 점: Work는 별도 프로그램이 아니다

ChatGPT Work는 독립 실행 프로그램의 이름이 아니라 **ChatGPT 안에서 선택하는 작업 방식**이다.

- 웹: `chatgpt.com`에 로그인하면 설치 없이 사용
- 데스크톱: ChatGPT 앱을 설치한 뒤 `ChatGPT → Work` 선택
- Work: 문서, 발표 자료, 분석 등 검토 가능한 결과물 제작
- Codex: 코드베이스를 중심으로 개발 작업 수행

따라서 “Work 설치”는 실제로 **ChatGPT 사용 환경을 준비하고 Work를 선택하는 과정**이다.

[공식 빠른 시작](https://learn.chatgpt.com/docs/quickstart)

---

## 계정과 플랜

필요한 것은 **로그인 가능한 ChatGPT 계정**이다.

공식 문서 기준 지원 플랜:

- 개인: Free, Go, Plus, Pro
- 조직: Business, Edu, Enterprise

Work와 Codex는 같은 사용량 한도를 공유한다. 사용 가능한 모델, 한도, 크레딧 정책은 플랜과 조직 계약에 따라 달라질 수 있다.

> API 키는 ChatGPT Work 로그인 수단이 아니다. 이 수업에서는 ChatGPT 계정으로 로그인한다.

[공식 플랜·사용량 안내](https://learn.chatgpt.com/docs/pricing)

---

## 화면에 보이는 기능은 서로 다를 수 있다

Work의 실제 사용 가능 범위는 다음 조건에 따라 달라질 수 있다.

- 가입한 플랜과 남은 사용량
- 개인 또는 조직 워크스페이스
- 조직 관리자가 허용한 역할과 기능
- 사용 중인 웹·모바일·데스크톱 환경
- 운영체제 권한과 제품 배포 상태

같은 앱을 설치해도 조직 정책에서 Work나 로컬 도구를 막았다면 사용할 수 없다.

[조직용 Work 관리자 FAQ](https://learn.chatgpt.com/docs/enterprise/work-admin-faq)

---

## 웹과 데스크톱 중 무엇을 선택할까?

| 구분 | 웹 | 데스크톱 앱 |
|---|---|---|
| 설치 | 필요 없음 | 필요함 |
| 시작 위치 | `chatgpt.com` | ChatGPT 앱 |
| 기본 작업 | 클라우드에서 작업 | 로컬·클라우드 작업 |
| 로컬 폴더·앱 | 직접 접근보다 업로드 중심 | 허용한 폴더·앱 사용 가능 |
| 추천 상황 | 빠른 시작, 설치 제한 PC | 로컬 파일, 여러 프로젝트, 장시간 작업 |

수업에서는 **웹으로 먼저 접속을 확인한 뒤 데스크톱 앱을 설치**한다.

[ChatGPT 데스크톱 앱](https://learn.chatgpt.com/docs/app)

---

## 설치 전 체크리스트

- ChatGPT 계정으로 로그인할 수 있는가?
- 수업에서 사용할 워크스페이스가 맞는가?
- PC에 프로그램을 설치할 권한이 있는가?
- 회사·학교 PC라면 설치 정책을 확인했는가?
- 실습용 폴더를 따로 만들었는가?
- 민감 정보가 없는 예제 파일을 준비했는가?

> 처음부터 문서·사진 전체 폴더를 허용하지 않는다.  
> 필요한 파일만 담은 실습 폴더로 시작한다.

# 2. ChatGPT Work 시작 방법

---

## 방법 A: 웹에서 바로 시작

1. [chatgpt.com](https://chatgpt.com/)에 접속한다.
2. ChatGPT 계정으로 로그인한다.
3. 새 대화를 연다.
4. 입력창 위 선택기에서 `Work`를 선택한다.
5. 새 프로젝트를 만들거나 필요한 파일을 업로드한다.
6. 원하는 결과와 완료 기준을 입력한다.

웹은 설치가 필요 없으므로 앱 설치가 제한된 환경의 대안이 된다.

[공식 빠른 시작](https://learn.chatgpt.com/docs/quickstart)

---

## 방법 B: 데스크톱 앱 설치

1. [ChatGPT 데스크톱 앱 공식 페이지](https://learn.chatgpt.com/docs/app)를 연다.
2. 운영체제에 맞는 다운로드 항목을 선택한다.
3. 내려받은 공식 설치 파일을 실행한다.
4. ChatGPT 앱을 열고 계정으로 로그인한다.
5. 새 대화, 프로젝트 또는 로컬 폴더를 연다.
6. `ChatGPT`를 선택한 뒤 입력창 위에서 `Work`로 전환한다.

> 설치 파일은 검색 광고나 제3자 배포 사이트가 아니라 공식 페이지에서 받는다.

---

## Windows 설치

### 그래픽 화면으로 설치

[Windows 앱 공식 안내](https://learn.chatgpt.com/docs/windows/windows-app)에서 다운로드한 뒤 안내에 따라 설치한다.

### PowerShell로 설치

```powershell
winget install --id 9PLM9XGG6VKS -s msstore
```

설치가 끝나면 시작 메뉴에서 `ChatGPT`를 실행한다. 조직에서 앱을 중앙 관리한다면 임의 설치 대신 관리자 배포 절차를 따른다.

[기업용 Windows 배포 안내](https://learn.chatgpt.com/docs/enterprise/windows-deployment)

---

## macOS 설치

1. [ChatGPT 데스크톱 앱 공식 페이지](https://learn.chatgpt.com/docs/app)를 연다.
2. 현재 제공되는 macOS용 설치 파일을 내려받는다.
3. 내려받은 파일의 안내에 따라 ChatGPT를 설치하고 실행한다.
4. macOS가 요청하는 파일·앱 접근 권한을 확인한다.
5. 계정으로 로그인한 뒤 `ChatGPT → Work`를 선택한다.

지원 CPU·운영체제와 다운로드 형식은 바뀔 수 있으므로 설치 직전에 공식 페이지를 확인한다.

---

## Linux 설치 전 확인

Linux 데스크톱 앱은 공식 문서에서 **Preview**로 안내한다.

2026-09-03 기준 지원 데스크톱 배포판:

- Ubuntu 24.04 LTS, 26.04 LTS
- Debian 13
- Fedora 43, 44
- CPU 아키텍처: x64, ARM64

```bash
uname -m
```

`x86_64`은 x64, `aarch64` 또는 `arm64`는 ARM64 패키지를 선택한다.

[Linux 앱 공식 안내](https://learn.chatgpt.com/docs/linux/linux-app)

---

## Linux 설치 명령

먼저 공식 문서에서 아키텍처에 맞는 `.deb` 또는 `.rpm` 파일을 내려받는다.

### Ubuntu·Debian x64 예시

```bash
cd ~/Downloads
sudo apt install ./chatgpt_amd64.deb
```

### Fedora x64 예시

```bash
cd ~/Downloads
sudo dnf install ./chatgpt.x86_64.rpm
```

ARM64는 공식 문서에 표시된 ARM64 파일명을 사용한다. 지원 배포판과 파일명은 설치 전에 다시 확인한다.

# 3. 첫 실행과 권한 설정

---

## 로그인 후 Work 열기

1. ChatGPT 앱을 실행하고 로그인한다.
2. 왼쪽에서 새 대화 또는 프로젝트를 만든다.
3. 제품 선택에서 `ChatGPT`를 선택한다.
4. 입력창 위 모드 선택에서 `Work`를 선택한다.
5. 작업에 필요한 파일이나 폴더만 추가한다.
6. 목표, 사용할 자료, 결과 형식, 완료 기준을 입력한다.

`Work`가 아니라 `Chat`이 선택되어 있지 않은지 확인한다.

[ChatGPT Work 시작하기](https://learn.chatgpt.com/docs/get-started-with-work)

---

## 로컬과 클라우드 선택

데스크톱 앱에서 해당 선택지가 제공되면 작업 위치를 고를 수 있다.

| 선택 | 적합한 상황 |
|---|---|
| Work locally | 내 컴퓨터의 파일·앱이 필요한 작업 |
| Cloud | 앱이나 PC를 닫은 뒤에도 계속할 작업 |

- 로컬 작업에는 데스크톱 앱과 운영체제 권한이 필요하다.
- 클라우드 선택지는 플랜·워크스페이스·배포 상태에 따라 다를 수 있다.
- 웹이나 모바일에서 이어서 볼 작업은 Cloud가 적합하다.

[로컬·클라우드 작업 안내](https://learn.chatgpt.com/docs/get-started-with-work#choose-local-or-cloud-work)

---

## 권한은 필요한 만큼만 허용

파일, 앱, 브라우저는 각각 별도의 권한과 승인을 사용한다.

- 수업용 폴더만 선택한다.
- 비밀번호, 개인정보, 계약서 등 민감 파일은 제외한다.
- 전송·게시·구매·삭제처럼 중요한 행동은 실행 전에 승인한다.
- 이미 로그인된 앱과 브라우저는 그 계정의 권한으로 정보에 접근할 수 있다.
- 조직 PC에서는 관리자 정책과 보안 지침을 우선한다.

> “로컬 작업”은 모델이 완전히 오프라인에서 동작한다는 뜻이 아니다. 작업 수행에 필요한 파일 일부와 도구 결과가 OpenAI 서비스로 전송될 수 있다.

[ChatGPT Work 로컬 보안](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-local-security)

---

## 설치 확인 실습

### 준비

`work-practice` 폴더를 만들고 민감 정보가 없는 `meeting.txt`를 넣는다.

### 실행

1. ChatGPT에서 Work를 선택한다.
2. 웹에서는 파일을 업로드하고, 앱에서는 실습 폴더를 연다.
3. 다음과 같이 요청한다.

```text
meeting.txt를 읽고 결정 사항과 할 일을 구분해 요약해 줘.
원본은 수정하지 말고 결과를 summary.md로 만들어 줘.
```

### 성공 기준

- Work가 요청을 시작한다.
- 원본은 그대로이고 결과 파일을 검토할 수 있다.
- 사용한 자료와 완료 결과가 보고된다.

---

## 문제가 생겼을 때

| 증상 | 확인할 항목 |
|---|---|
| Work가 보이지 않음 | 계정·플랜·워크스페이스·관리자 권한 확인 |
| 앱 설치가 차단됨 | 웹 사용 또는 조직 관리자에게 설치 요청 |
| 폴더를 읽지 못함 | 선택한 폴더와 OS 파일 권한 확인 |
| 로컬·Cloud 선택이 다름 | 플랫폼과 기능 배포 상태 확인 |
| 사용량 제한 메시지 | 현재 플랜의 공유 사용량과 크레딧 확인 |
| 앱 화면이 문서와 다름 | 앱 업데이트 후 공식 빠른 시작 재확인 |

출처가 불분명한 설치 파일이나 비공식 우회 방법은 사용하지 않는다.

---

## 수업 시작 전 최종 점검

- [ ] ChatGPT 계정으로 로그인했다.
- [ ] 개인·조직 워크스페이스를 올바르게 선택했다.
- [ ] 새 대화에서 Work 선택기가 보인다.
- [ ] 웹 또는 데스크톱 중 사용할 환경을 정했다.
- [ ] 실습 폴더와 예제 파일을 준비했다.
- [ ] 필요한 범위의 권한만 허용했다.
- [ ] 테스트 요청의 결과물을 직접 열어 확인했다.

설치의 완료 기준은 앱 아이콘이 생긴 것이 아니라 **Work에서 안전하게 결과물을 만들고 검토할 수 있는 상태**이다.
