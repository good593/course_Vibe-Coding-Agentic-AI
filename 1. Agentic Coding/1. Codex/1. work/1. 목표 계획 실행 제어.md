# 목표·계획·실행 제어

Goal·Plan Mode·모델·승인으로 긴 업무 통제하기

---

## 오늘의 목표

- 검증 가능한 Work 브리핑을 작성한다.
- Plan Mode에서 단계와 승인 지점을 검토한다.
- Goal이 적합한 장기 업무를 구분한다.
- 진행 중 질문·수정·중단으로 방향을 제어한다.

---

## Work 브리핑의 여섯 요소

1. 목표: 어떤 결과물이 필요한가?
2. 독자: 누가 어떤 결정을 내리는가?
3. 입력: 어떤 자료와 출처를 사용해야 하는가?
4. 제약: 제외할 범위와 지켜야 할 정책은?
5. 완료 기준: 무엇을 확인하면 끝인가?
6. 보고: 어떤 근거와 한계를 남길 것인가?

---

## 브리핑 예시

```text
목표: 신규 예약 서비스 출시 여부를 위한 2쪽 의사결정 메모 작성
독자: 제품 책임자와 운영 책임자
입력: 인터뷰 8개, 설문 CSV, 경쟁사 공식 페이지
제약: 2026-08 이후 자료 우선, 개인정보 제외
완료 기준: 기회·위험·권고안·반대 근거 포함
보고: 출처 목록, 불일치, 미확인 질문
```

---

## Plan Mode

실행 전에 다음을 검토한다.

- 필요한 자료가 모두 있는가?
- 어떤 단계를 어떤 순서로 진행하는가?
- 외부 검색과 연결 도구가 필요한가?
- 어디에서 사람의 승인이 필요한가?
- 결과를 어떻게 검산·역검증하는가?

계획이 틀리면 실행 속도보다 먼저 수정한다.

---

## Goal

Goal에 적합한 업무:

- 여러 턴 또는 장시간 이어지는 조사
- 반복적인 자료 수집과 산출물 개선
- 중간 결과를 보고받고 방향을 바꿔야 하는 작업

좋은 Goal에는 완료 조건·계속 진행 조건·멈추고 질문할 조건이 있다.

---

## 모델과 추론 수준

| 작업 | 선택 관점 |
|---|---|
| 정리·형식 변환 | 속도와 비용 |
| 여러 출처 비교 | 근거 처리와 추론 |
| 의사결정·복합 분석 | 더 높은 추론 + 명확한 검증 |
| 외부 행동 | 모델보다 좁은 권한과 승인 |

강한 모델도 누락·오해·잘못된 출처를 만들 수 있다.

---

## 승인 지점

실행 전 별도 확인이 필요한 예:

- 외부 메시지 발송
- 일정 생성·수정
- 파일 공유 범위 변경
- 게시·구매·예약·결제
- 삭제 또는 덮어쓰기

“분석 승인”과 “외부 행동 승인”을 분리한다.

---

## 진행 중 방향 수정

```text
지금까지 확인한 출처와 잠정 결론만 보여줘.
가격 비교는 중단하고 사용자 전환 비용에 집중해줘.
공식 출처가 없는 주장은 별도 표로 분리해줘.
외부 쓰기 작업은 실행하지 말고 초안만 만들어줘.
```

중간 결과를 볼 때 이미 사용한 출처와 남은 단계를 확인한다.

---

## 강사 시연

1. 모호한 조사 요청을 Work 브리핑으로 바꾼다.
2. Plan Mode에서 누락 자료와 승인 지점을 찾는다.
3. Goal을 설정하고 첫 중간 보고를 받는다.
4. 조사 방향을 수정한다.
5. 외부 행동 직전에 멈추게 한다.

---

## 실습

제품 조사 과제를 설계한다.

- Work 브리핑 작성
- Plan 검토와 수정
- Goal 완료·중단 조건 설정
- 중간 진행 보고 요청
- 방향 수정 1회
- 최종 결과의 근거와 미확인 항목 검토

---

## 평가 기준

- 결과물과 독자가 분명한가?
- 입력 자료와 허용 출처가 구체적인가?
- 승인과 중단 지점이 있는가?
- 모델·추론 선택 이유를 설명하는가?
- 미확인 사항을 사실처럼 표현하지 않았는가?
