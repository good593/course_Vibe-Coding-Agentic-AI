# Skills와 예약 자동화

Record & Replay·Scheduled tasks·Notifications로 반복 업무 운영하기

---

## 오늘의 목표

- 반복 가능한 업무를 Skill로 정의한다.
- Record & Replay가 적합한 화면 작업을 구분한다.
- Scheduled task의 입력·주기·승인·실패 처리를 설계한다.
- Notifications와 실행 기록으로 자동화 결과를 검토한다.

---

## 무엇을 자동화할까

좋은 후보:

- 입력 형식과 절차가 반복된다.
- 완료 기준이 명확하다.
- 실패를 확인할 수 있다.
- 사람의 판단 지점이 정의되어 있다.
- 잘못 실행해도 피해가 제한적이다.

정책 결정·민감 메시지·결제처럼 맥락 의존성이 높은 일은 완전 자동화하지 않는다.

---

## Skill

Skill은 반복 업무의 작업법을 재사용한다.

정의할 것:

- 언제 사용할지
- 필요한 입력과 승인된 출처
- 단계와 도구
- 출력 형식
- 검증 방법
- 중단하고 질문할 조건
- 사용하면 안 되는 상황

---

## 주간 제품 업데이트 Skill

```text
입력:
- 지난주 지표 스프레드시트
- 승인된 고객 피드백
- 변경된 일정

출력:
- 핵심 변화 3개
- 위험과 결정 요청
- 출처 링크
- 누락·불일치 데이터

중단:
- 원자료 갱신 실패
- KPI 정의 변경
- 개인정보 발견
```

---

## Record & Replay

지원되는 환경에서 사람이 화면 작업을 시연하고 재사용 가능한 Skill 흐름으로 만들 수 있다.

적합한 예:

- 반복적인 내부 시스템 조회
- 정해진 화면 순서의 보고서 준비
- 여러 앱을 오가는 입력 절차

기록 전 화면의 개인정보·계정·권한을 정리하고, 생성된 절차를 반드시 검토한다.

---

## Scheduled task 설계

| 항목 | 예시 |
|---|---|
| 목적 | 매주 월요일 제품 업데이트 초안 |
| 주기 | 월요일 09:00 Asia/Seoul |
| 입력 | 승인된 Drive 폴더와 지표 파일 |
| 실행 환경 | Cloud |
| 외부 쓰기 | 게시하지 않고 초안만 저장 |
| 성공 조건 | 출처·갱신 시각·누락 데이터 포함 |
| 실패 처리 | 알림 후 사람 검토 대기 |

---

## 예약 작업과 Site

- Site: 결과를 보여주는 화면
- Scheduled task: 정해진 시간에 자료를 확인하고 결과를 갱신하는 실행
- Notification: 완료·실패·주의가 필요한 상태 전달

Site를 만들었다고 데이터가 자동으로 최신화되는 것은 아니다.

---

## Notifications

좋은 알림은 사람이 행동해야 하는 정보만 전달한다.

- 무엇이 실행되었는가?
- 성공·실패·부분 성공 중 무엇인가?
- 데이터 기준 시각은 언제인가?
- 어떤 결정이나 승인이 필요한가?
- 실행 기록으로 어떻게 이동하는가?

변화가 없을 때 알리지 않는 조건도 고려한다.

---

## 실패와 중복 실행

확인할 것:

- 입력 소스 접근 실패
- 일부 파일만 갱신
- 같은 작업 중복 실행
- 시간대·휴일 문제
- 외부 서비스 쓰기 실패
- 오래된 결과가 최신 결과를 덮어씀

자동화는 조용히 틀리는 것보다 명확히 실패하는 편이 낫다.

---

## 강사 시연

1. 수동 주간 업데이트 수행
2. 반복 단계와 판단 단계 분리
3. Skill로 절차 저장
4. Scheduled task와 실행 주기 설정
5. 실패 입력으로 실행
6. Notifications와 실행 기록 검토

---

## 실습

주간 제품 업데이트를 자동화한다.

- Skill 정의
- 샘플 자료로 수동 실행
- 예약 작업 생성
- 외부 게시는 비활성화
- 정상·입력 누락 두 경우 테스트
- 알림과 실행 기록 검토

대체 실습: Record & Replay 또는 예약 기능이 없으면 Skill 명세와 실행 시나리오를 작성하고 수동으로 두 번 재현한다.

---

## 제출물

- Skill 또는 Skill 명세
- Scheduled task 설정표
- 정상·실패 실행 결과
- Notification 예시
- 사람이 검토·승인해야 하는 지점
- 자동화하지 않기로 한 항목과 이유
