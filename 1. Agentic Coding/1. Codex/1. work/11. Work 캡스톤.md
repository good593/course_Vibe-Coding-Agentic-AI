# ChatGPT Work 캡스톤

7개 이상의 기능군을 연결해 검토 가능한 제품 기획 워크스페이스 완성하기

---

## 프로젝트 목표

새 제품 브리프와 독립 자료 팩을 사용해 다음 흐름을 완성한다.

```text
자료 구성 → 조사 → 데이터 분석 → PRD
         → 의사결정 덱 → Site → 반복 업데이트
```

산출물의 양보다 근거·검증·권한·재사용 가능한 흐름을 평가한다.

---

## 사용할 제품 주제

다음 중 하나를 선택하거나 강사 주제를 사용한다.

- 지역 기반 반려동물 돌봄 매칭
- 직장인 건강 루틴 코칭
- 소규모 팀 회의 후속 관리
- 지역 행사 발견과 일정 계획

앞 차시의 예약 서비스 자료를 그대로 복사하지 않고 새 자료에서 시작한다.

---

## 필수 기능군

다음 중 7개 이상을 사용한다.

1. Projects·Chats
2. Goal·Plan Mode
3. Files·folders·images·Appshots
4. Web search·Browser
5. Documents·PDF
6. Spreadsheets·Visualizations
7. Presentations·image generation
8. Plugins·Computer use
9. Sites
10. Skills·Scheduled tasks·Notifications
11. Long-running work·Subagents

---

## 1단계: Project 설계

- 제품과 의사결정 목적 정의
- 공통 Sources와 Project 지침 추가
- 산출물별 Chat 분리
- 민감정보와 사용 금지 자료 확인
- 기능 사용 계획과 대체 기능 정리

각 Chat은 하나의 완료 목표를 가져야 한다.

---

## 2단계: 목표와 조사

- Goal·Plan Mode로 단계 설계
- 기준일·지역·출처 정책 정의
- 필요한 경우 Subagents로 독립 조사
- 원문 표본 대조
- 근거·반대 근거·한계 표 작성

장기 작업은 중간 보고에서 한 번 이상 방향을 검토한다.

---

## 3단계: 분석

- 데이터 계약 작성
- 원본 보존과 정리본 분리
- 지표·수식·제외 기준 명시
- 표본 검산
- 차트와 Visualization 생성
- 사실·추론·의사결정 분리

잘못된 데이터는 그럴듯한 Site와 덱으로도 고쳐지지 않는다.

---

## 4단계: PRD와 덱

- 근거가 연결된 PRD
- 범위·비범위·예외·미결정 사항
- 편집 가능한 최종 문서와 PDF
- 의사결정용 5장 덱
- 핵심 수치 역검증
- 생성 이미지는 콘셉트임을 표시

---

## 5단계: Site

- KPI와 우선순위 현황
- 원자료·지표 정의·최근 업데이트
- 필터와 빈 상태
- 모바일 확인
- 공유 전 개인정보와 접근 범위 검토

Site에는 샘플 데이터 여부를 명확히 표시한다.

---

## 6단계: 재사용과 자동화

다음 중 하나 이상을 구현한다.

- 반복 절차 Skill
- Record & Replay 흐름
- Scheduled task

필수:

- 정상·실패 조건
- Notification
- 외부 쓰기 승인 지점
- 사람이 최종 확인할 항목

---

## 기능 사용 기록

| 기능 | 사용 목적 | 입력 | 결과 | 검증 | 한계 |
|---|---|---|---|---|---|
| Web search | 시장 근거 | 조사 질문 | 근거표 | 원문 대조 | 일부 유료 자료 |

기능 개수를 채우기 위한 불필요한 사용은 감점한다.

---

## 발표에서 설명할 것

- 어떤 결정을 위해 무엇을 만들었는가?
- Work가 가장 잘한 일은 무엇인가?
- 잘못된 가정이나 오류는 무엇이었는가?
- 사람이 어디에서 방향을 바꾸거나 승인했는가?
- 반복 업무를 어떻게 재사용하게 만들었는가?
- 실제 조직에 적용하려면 어떤 정책이 필요한가?

## 평가 기준

| 영역 | 배점 | 핵심 질문 |
|---|---:|---|
| 기능 활용 | 35 | 기능 선택이 목적과 맞고 연결되어 있는가? |
| 결과물 품질 | 20 | 독자가 실제로 검토·사용할 수 있는가? |
| 출처·검증 | 20 | 근거·수식·수치를 역검증했는가? |
| 권한·안전 | 15 | 최소 권한과 외부 행동 승인이 적절한가? |
| 재사용·자동화 | 10 | 반복 실행과 실패 처리가 설계됐는가? |

---

## 감점 기준

- 출처 없는 수치와 단정
- 실제 개인정보·회사 비밀 사용
- 원본 데이터 덮어쓰기
- 검토 없이 외부 발송·공유·게시
- 제공되지 않는 기능을 사용했다고 기록
- 실패·미확인 항목 누락
- 기능 수를 채우기 위한 억지 연결

## 최종 체크리스트
