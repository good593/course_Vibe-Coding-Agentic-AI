# 발표자료와 이미지

근거 있는 의사결정 덱과 오해 없는 콘셉트 이미지 만들기

---

## 오늘의 목표

- 독자와 결정을 중심으로 발표 구조를 설계한다.
- 기존 템플릿을 재사용해 편집 가능한 덱을 만든다.
- PRD·데이터와 슬라이드 수치를 연결한다.
- 생성 이미지의 용도와 한계를 명확히 표시한다.

---

## 발표자료 브리핑

```text
독자: 제품 책임자와 운영 책임자
결정: 6주 MVP 실험 승인 여부
길이: 본문 5장 + 부록
근거: 최종 PRD와 검산된 스프레드시트
템플릿: 제공된 회사 덱
필수: 기회, 문제, 제안, 지표, 위험과 요청
```

---

## 5장 의사결정 구조

1. 왜 지금 결정해야 하는가?
2. 누구의 어떤 문제가 확인되었는가?
3. 무엇을 작게 실험할 것인가?
4. 어떤 지표로 판단할 것인가?
5. 위험·비용·의사결정 요청은 무엇인가?

부록에는 출처·세부 데이터·대안 비교를 둔다.

---

## 한 장, 한 메시지

슬라이드마다 확인한다.

- 제목만 읽어도 주장 흐름이 이어지는가?
- 표·차트가 제목의 주장을 증명하는가?
- 본문이 데이터보다 많지 않은가?
- 다음 결정에 필요하지 않은 장식이 있는가?
- 수치의 단위·기간·출처가 보이는가?

---

## Template Creator

기존 발표자료를 재사용할 때:

- 마스터·레이아웃과 글꼴 확인
- 제목·본문·표·차트 유형 분류
- 템플릿에서 데이터와 고객명을 제거
- 편집 가능한 요소 유지
- 강사 또는 조직이 승인한 자료만 사용

계정에서 제공되지 않으면 기존 PPTX를 직접 참조 자료로 사용한다.

---

## 수치 역검증

| 슬라이드 | 주장 | 원본 위치 | 계산 | 확인자 |
|---|---|---|---|---|
| 2 | 재예약 의향 61% | survey.xlsx Q12 | 122/200 | 수강생 |

슬라이드 수치를 원본 표본과 다시 대조한다. 반올림과 제외 기준도 표시한다.

---

## 이미지 생성

적합한 용도:

- 제품 분위기와 사용자 상황 탐색
- 발표자료의 콘셉트 비주얼
- 아이디어 비교용 저충실도 시안

주의:

- 실제 구현 화면이나 확정 디자인처럼 표현하지 않는다.
- 인물·브랜드·저작권·편향을 검토한다.
- 이미지 속 텍스트와 수치는 다시 작성한다.

---

## 이미지 프롬프트 구조

```text
목적: 예약 서비스 MVP 콘셉트 설명
장면: 퇴근 후 소규모 공예 클래스를 찾는 직장인
스타일: 편집용 발표자료에 어울리는 단순한 에디토리얼 일러스트
구도: 오른쪽에 제목 공간 확보
제외: 로고, 읽기 어려운 UI 텍스트, 실제 서비스처럼 보이는 화면
```

---

## 강사 시연

- PRD와 스프레드시트 연결
- 제공 템플릿으로 5장 덱 생성
- 미리보기에서 레이아웃 수정
- 수치 3개 원본 역검증
- 콘셉트 이미지 생성과 “예시 이미지” 표시

---

## 실습

MVP 승인 덱을 만든다.

- 5장 본문과 출처 부록
- 기존 템플릿 적용
- 차트 최소 1개
- 핵심 수치 3개 역검증
- 콘셉트 이미지 1개
- 이미지와 실제 기능 범위의 차이 명시

대체 실습: Template Creator를 사용할 수 없으면 참조 덱의 레이아웃을 명시해 새 파일을 만든다.

---

## 제출물

- 편집 가능한 발표자료
- 출처와 수치 검증표
- 템플릿 적용 전후 비교
- 생성 이미지와 사용 목적
- 의사결정 요청 한 문장
