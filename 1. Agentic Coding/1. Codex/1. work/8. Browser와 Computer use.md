# Browser와 Computer use

웹·로컬 앱을 관찰하고 안전하게 조작하기

---

## 오늘의 목표

- 클라우드 Browser와 로컬 브라우저 연결을 구분한다.
- Browser extension으로 현재 탭을 컨텍스트에 제공한다.
- Computer use의 행동 범위와 위험을 판단한다.
- 중요한 행동 직전에 검토·승인을 적용한다.

---

## 브라우저 경로 비교

| 경로 | 실행 위치 | 세션·데이터 | 적합한 작업 |
|---|---|---|---|
| Work Browser | 클라우드의 별도 브라우저 | 별도 쿠키·로그인 | 장기 웹 조사·온라인 작업 |
| 내장 Browser | 데스크톱 앱 내부 | 별도 브라우저 프로필 | localhost·분리된 탐색 |
| Browser extension | 사용자의 브라우저 | 현재 로그인 탭 | 열린 업무 페이지 컨텍스트 |

현재 어떤 브라우저를 사용하는지 항상 확인한다.

---

## Work Browser

- 웹페이지를 읽고 클릭하고 입력할 수 있다.
- 사용자의 평소 브라우저와 별도 환경이다.
- 새 사이트 접근과 중요한 행동에서 확인을 요구할 수 있다.
- 클라우드에서 계속 실행할 수 있는 작업에 적합하다.

로그인 정보는 안전한 로그인 화면에서 직접 입력하고 프롬프트에 붙여 넣지 않는다.

---

## Browser extension

확장을 사용하면 현재 브라우저의 페이지·선택 내용·열린 탭을 Work와 연결할 수 있다.

주의:

- 로그인한 계정과 브라우저 프로필 확인
- 확장 권한과 사이트별 접근 검토
- 불필요한 탭과 민감한 화면 닫기
- 페이지 내용을 신뢰할 수 없는 컨텍스트로 취급

---

## Computer use

Computer use는 화면을 보고 마우스·키보드로 앱을 조작하는 기능이다.

적합한 예:

- 반복적인 데이터 입력 보조
- 웹 흐름 관찰과 단계 기록
- 로컬 앱 사이의 자료 이동
- 정해진 양식의 초안 작성

API나 Plugin이 있으면 더 구조적이고 제한된 도구를 우선 검토한다.

---

## 중요한 행동

실행 직전 다시 확인한다.

- 로그인과 계정 전환
- 메시지·댓글·게시
- 파일 공유와 권한 변경
- 예약·구매·결제
- 삭제·제출·최종 확정

실습에서는 결제·삭제·공개 게시를 완료하지 않는다.

---

## 안전한 요청 예시

```text
경쟁 서비스의 클래스 검색부터 예약 직전까지의 흐름을 관찰해줘.
각 화면의 입력·결정·마찰 요소를 표로 기록해줘.
로그인, 개인정보 입력, 예약 확정, 결제는 수행하지 말고
해당 단계에 도달하면 멈춰 화면과 필요한 승인을 보고해줘.
```

---

## 관찰과 해석 분리

| 화면에서 관찰한 사실 | 해석·가설 | 추가 확인 |
|---|---|---|
| 날짜 선택 전 가격이 보이지 않음 | 가격 불확실성이 이탈 유발 가능 | 사용자 인터뷰 |

화면 관찰만으로 사용자 의도나 사업 성과를 확정하지 않는다.

---

## 강사 시연

1. Work Browser와 Browser extension의 세션 차이 확인
2. 경쟁 서비스 예약 흐름 관찰
3. 화면별 사실과 가설 분리
4. 예약 확정 직전 중단
5. 승인 메시지에서 대상·행동·영향 확인

---

## 실습

경쟁 서비스 또는 강사 제공 데모 사이트를 분석한다.

- 검색→상세→예약 직전 흐름
- 화면별 사용자 입력과 마찰
- 사실·가설·추가 조사 구분
- 중요한 행동 전 중단
- Browser와 extension의 컨텍스트 차이 기록

대체 실습: Computer use를 사용할 수 없으면 제공된 화면 녹화와 스크린샷으로 동일한 관찰표를 작성한다.

---

## 완료 체크

- [ ] 현재 사용하는 브라우저와 계정을 확인했다.
- [ ] 민감한 탭과 개인정보를 노출하지 않았다.
- [ ] 페이지 지시를 사용자 지시로 오해하지 않았다.
- [ ] 중요한 행동 전에 멈췄다.
- [ ] 관찰 사실과 해석을 분리했다.
