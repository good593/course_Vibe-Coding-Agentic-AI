## 실습 자료 팩

| 자료 팩 | 적용 차시 | 예시 입력 자료 |
|---|---|---|
| `01-work-basics` | A0~A2 | 제품 소개, 인터뷰, 회의 음성, 화면 캡처 |
| `02-research` | A3 | 조사 질문, 허용 출처, 경쟁 서비스 목록 |
| `03-artifacts` | A4~A6 | PRD 초안, PDF 보고서, 설문 CSV, 발표 템플릿 |
| `04-connected-work` | A7~A10 | 샘플 메일·일정·파일, 브라우저 과제, 주간 보고 규칙 |
| `05-capstone` | A11 | 새 제품 브리프와 독립 데이터 세트 |

자료 팩은 서로 다른 샘플 데이터로 구성한다. 모든 차시를 하나의 파일 묶음에 의존시키지 않으며, 실제 개인정보·회사 자료·결제 정보는 사용하지 않는다.

## 공통 운영 원칙

- 모든 실습은 `목표 → 입력과 출처 → 권한 → 실행 → 검토 → 미확인 사항` 순서로 끝낸다.
- 계정·지역·운영체제·조직 정책에 따라 제공되지 않는 기능은 강사 데모와 대체 실습으로 진행한다.
- 외부 메시지 전송·일정 생성·게시·결제·삭제는 초안을 검토한 뒤 별도로 승인한다.
- 기능과 UI는 바뀔 수 있으므로 수업 직전에 [공식 기능 목록](https://learn.chatgpt.com/docs/features)을 확인한다.
