## 공통 운영 방식

- 예제 프로젝트: `동네 클래스 예약 서비스`
- 매 차시 종료: 변경 파일, 실행 명령, 테스트 결과, 미검증 항목 기록
- 쓰기·외부 전송·삭제·배포 작업: 실행 전 대상과 영향 범위 확인
- 조건부 기능: 사용할 수 없으면 공식 문서와 강사 화면으로 흐름을 익힌 뒤 대체 실습 수행
- 기능과 명령은 변경될 수 있으므로 수업 직전에 [공식 기능 목록](https://learn.chatgpt.com/docs/features)을 확인
